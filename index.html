Speaker notes

Notes only show on your screen and are never recorded. Click ✎ on the notes box to type or edit them. Notes are saved per PDF file name.

Timer

to min

While recording, the timer shows the video's length (paused time doesn't count). Otherwise press T to run a practice timer. Slide targets come from cues in your notes like "(About 45 seconds.)". Set both targets to 0 to turn the range off.

Recording

Takes

Each slide is its own take, saved in this browser as you go. You can close the browser and continue later. Save video joins the takes into one MP4. Click a take to jump to its slide, or ✕ to delete it.

Shortcuts

→ Space PgDn next · ← PgUp previous
R record / pause / resume · Z redo this slide · C camera · H hide this panel
T practice timer · N floating notes · V presenter view · + − notes text size · Esc finish editing
Presentation clickers work too. Keep this tab open while recording.

Import speaker notes from your script
